# Своя игра

## Перенос на новый компьютер с Windows

Скопируйте или распакуйте всю папку проекта в одно место. Сохраните имена файлов и расположение папки с материалами. В примере ниже она называется `22.11.26`.

```text
Своя игра/
├── index.html         # Интерфейс и логика игры
├── style.css          # Оформление
├── database.js        # Темы, стоимости и база вопросов
├── media-index.js     # Сгенерированный индекс материалов
├── build-database.cjs    # Скрипт обновления индекса
└── 22.11.26/          # Изображения, аудио, видео и текстовые файлы
```

Установите Python 3 для запуска локального сервера. [Скачать Python для Windows](https://www.python.org/downloads/windows/)

Node.js понадобится, если нужно пересобрать `media-index.js`. Если вы перенесли готовый индекс и материалы совпадают с ним, можно сразу запускать игру. [Скачать Node.js LTS](https://nodejs.org/en/download)

## Запуск игры

1. Откройте папку с `index.html` в Проводнике. Щёлкните по адресной строке, введите `powershell` и нажмите Enter. PowerShell откроется в папке игры.
2. Запустите сервер.

   ```powershell
   py -m http.server 8000 --bind 127.0.0.1
   ```

   Если команда `py` недоступна, используйте `python -m http.server 8000 --bind 127.0.0.1`.
3. Откройте игру в браузере и нажмите «Начать». В адресе должен быть порт `:8000`. [Открыть игру](http://127.0.0.1:8000/index.html)
4. Оставьте окно PowerShell открытым на время игры. Чтобы остановить сервер, нажмите `Ctrl+C`.

Кнопка «Показать ответ» заменяет содержимое карточки ответом. Кнопка «Показать вопрос» возвращает вопрос. Следующий раунд начинается после возврата к сетке с последнего сыгранного вопроса текущего раунда.

## Обновление материалов

Файлы вопроса и ответа лежат в одной папке рядом с `index.html`. Папка может называться как угодно. Если вы переименовали её, укажите новое имя в настройке папки в `build-database.cjs` и заново запустите `node build-database.cjs`, чтобы обновить пути в `media-index.js`.

В имени `r2t1q3` цифры обозначают второй раунд, первую тему и третий вопрос в этой теме по порядку стоимостей из `database.js`. Добавьте суффикс `_question` для вопроса или `_answer` для ответа.

Например, `r2t1q3_question.jpg` — картинка вопроса, а `r2t1q3_answer.mp4` — видео ответа. Если текст берётся из `.txt`, сохраняйте его в UTF-8. Для отображения переносов строк в карточке у `#questionText` и `#answerText` должно быть задано `white-space: pre-line` в `style.css`.

После добавления, удаления или переименования материалов, а также после изменения текста в индексируемом `.txt), выполните из папки проекта:

```powershell
node build-database.cjs
```

Скрипт обновит `media-index.js`. Обновите страницу в браузере через `Ctrl+F5`. Если вы изменили только `database.js` или оформление, достаточно обновить страницу.

## Если игра не запускается

| Симптом | Что проверить |
| --- | --- |
| Браузер не подключается | Сервер запущен, окно PowerShell открыто, а в адресе указан порт `:8000`. Если порт занят, запустите сервер с `8001` и укажите `:8001` в адресе. |
| Сервер возвращает `404` для `index.html` | Выполните `Get-ChildItem -Name` в папке запуска и проверьте, что в списке есть `index.html`. |
| Картинка, звук или видео отсутствуют | Проверьте, что файл скопирован в папку с материалами, а имя и расширение совпадают с путём в `media-index.js`. Попробуйте открыть этот путь напрямую через тот же сервер. |
| Страница есть, но кнопка «Начать» не работает | Проверьте наличие `media-index.js` и `database.js`. В `index.html` индекс должен подключаться перед базой, а база — перед скриптом игры. |
