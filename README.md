# Своя игра

## Перенос на новый компьютер с Windows

Если проект хранится на GitHub, установите Git для Windows. [Скачать Git](https://git-scm.com/download/win)

Откройте репозиторий на GitHub, нажмите **Code → HTTPS** и скопируйте адрес.

1. Откройте Проводник Windows (`Win+E`) и перейдите в папку, где хотите сохранить проект, например «Документы». Git создаст внутри неё отдельную папку репозитория.
2. Нажмите `Ctrl+L`, чтобы выделить путь в адресной строке Проводника. Введите `powershell` и нажмите `Enter`.
3. В открывшемся окне выполните `Get-Location`, чтобы проверить, что PowerShell запустился в выбранной папке.

Выполните команды, подставив адрес своего репозитория и имя созданной папки.

```powershell
git clone https://github.com/OWNER/REPOSITORY.git
cd REPOSITORY
```

Если у вас уже есть копия проекта или архив, скопируйте или распакуйте папку целиком. Если материалы хранятся отдельно от репозитория, скопируйте их папку рядом с `index.html`. Сохраните имена файлов. В примере ниже папка с материалами называется `22.11.26`.

```text
Своя игра/
├── index.html         # Интерфейс и логика игры
├── style.css          # Оформление
├── database.js        # Темы, стоимости и база вопросов
├── media-index.js     # Сгенерированный индекс материалов
├── build-database.cjs    # Скрипт обновления индекса
└── 22.11.26/          # Изображения, аудио, видео и текстовые файлы
```

Установите Python 3 для запуска локального сервера. [Скачать Python для Windows](https://www.python.org/downloads/windows/)

Node.js понадобится, если нужно пересобрать `media-index.js`. Если вы перенесли готовый индекс и материалы совпадают с ним, можно сразу запускать игру. [Скачать Node.js LTS](https://nodejs.org/en/download)

## Запуск игры

1. Откройте папку с `index.html` в Проводнике. Щёлкните по адресной строке, введите `powershell` и нажмите Enter. PowerShell откроется в папке игры.
2. Запустите сервер.

   ```powershell
   py -m http.server 8000 --bind 127.0.0.1
   ```

   Если команда `py` недоступна, используйте `python -m http.server 8000 --bind 127.0.0.1`.
3. Откройте игру в браузере и нажмите «Начать». В адресе должен быть порт `:8000`. [Открыть игру](http://127.0.0.1:8000/index.html)
4. Оставьте окно PowerShell открытым на время игры. Чтобы остановить сервер, нажмите `Ctrl+C`.

Кнопка «Показать ответ» заменяет содержимое карточки ответом. Кнопка «Показать вопрос» возвращает вопрос. Следующий раунд начинается после возврата к сетке с последнего сыгранного вопроса текущего раунда.

## Настройка раундов, тем и стоимости

Откройте `database.js`. Внешние массивы `themes` и `points` содержат по одному списку на раунд. Первый список относится к первому раунду, второй — ко второму и так далее.

```js
const themes = [
  ['СНАРЯЖЕНИЕ', 'ВЕРШИНЫ МИРА'],
  ['МЕМОЛОГИЯ', 'ВЕРШИНЫ РОССИИ'],
];

const points = [
  [200, 400, 600, 800, 1200],
  [400, 800, 1200, 1600, 2000],
];
```

- **Количество раундов.** Добавьте или удалите список в обоих массивах на одной и той же позиции. В `databaseQuestions` должна быть запись для каждого раунда. Если записи создаются циклом, убедитесь, что он создаёт объект для каждого раунда и каждой темы перед заполнением вопросов.
- **Темы.** Измените названия или состав списка нужного раунда в `themes`. Если вопросы заданы вручную, обновите ключи тем в соответствующем объекте `databaseQuestions`.
- **Стоимость и число вопросов по умолчанию.** Измените числа в списке нужного раунда в `points`. Длина списка задаёт число вопросов в каждой теме этого раунда, если для темы нет своего списка в `uniquePoints`. В списке может быть разное число элементов для разных раундов. Если вопросы заданы вручную в `databaseQuestions`, обновите поле `points` у соответствующих вопросов.

### Индивидуальные настройки тем в раунде

Чтобы изменить стоимость или число вопросов во всём раунде, отредактируйте его список в `points`. Для отдельных тем добавьте записи в `uniquePoints` в файле `database.js`. В ключе `r1t6` число после `r` — номер раунда, а число после `t` — номер темы. Оба номера начинаются с 1. Темы без записи в `uniquePoints` берут список из `points` для своего раунда.

```js
const uniquePoints = {
  r1t6: [500, 500, 500, 500, 500],
  r2t1: [300, 500, 700],
};
```

В этом примере шестая тема первого раунда содержит пять отдельных вопросов по 500 очков, а первая тема второго раунда — три вопроса за 300, 500 и 700. Для них используйте имена медиафайлов от `r1t6q1` до `r1t6q5` и от `r2t1q1` до `r2t1q3`.

Для этих настроек используйте обновлённые `database.js` и `index.html` вместе. В `databaseQuestions[номерРаунда - 1][названиеТемы]` ключ вопроса — его номер, начиная с 1, а стоимость хранится в поле `points` самого вопроса. Сетка показывает минимум пять столбцов для вопросов и расширяется по самой длинной теме раунда. Короткие строки дополняются пустыми ячейками. Для перехода дальше нужно сыграть только вопросы из базы.

Имена медиафайлов привязаны к **порядку** раундов, тем и стоимостей. Например, `r2t1q3` — третий вопрос первой темы второго раунда. Если меняете порядок или вставляете тему, раунд либо стоимость в середину списка, проверьте имена затронутых файлов. После переименования пересоберите индекс командой `node build-database.cjs`. Если поменяли только название темы или сумму очков на той же позиции, имена медиафайлов сохраняются.

## Обновление материалов

Файлы вопроса и ответа лежат в одной папке рядом с `index.html`. Папка может называться как угодно. Если вы переименовали её, укажите новое имя в настройке папки в `build-database.cjs` и заново запустите `node build-database.cjs`, чтобы обновить пути в `media-index.js`.

В имени `r2t1q3` цифры обозначают второй раунд, первую тему и третий вопрос в этой теме по порядку стоимостей из `database.js`. Добавьте суффикс `_question` для вопроса или `_answer` для ответа.

Например, `r2t1q3_question.jpg` — картинка вопроса, а `r2t1q3_answer.mp4` — видео ответа. Если текст берётся из `.txt`, сохраняйте его в UTF-8. Для отображения переносов строк в карточке у `#questionText` и `#answerText` должно быть задано `white-space: pre-line` в `style.css`.

После добавления, удаления или переименования материалов, а также после изменения текста в индексируемом `.txt), выполните из папки проекта:

```powershell
node build-database.cjs
```

Скрипт обновит `media-index.js`. Обновите страницу в браузере через `Ctrl+F5`. Если вы изменили только `database.js` или оформление, достаточно обновить страницу.

## Если игра не запускается

| Симптом | Что проверить |
| --- | --- |
| Браузер не подключается | Сервер запущен, окно PowerShell открыто, а в адресе указан порт `:8000`. Если порт занят, запустите сервер с `8001` и укажите `:8001` в адресе. |
| Сервер возвращает `404` для `index.html` | Выполните `Get-ChildItem -Name` в папке запуска и проверьте, что в списке есть `index.html`. |
| Картинка, звук или видео отсутствуют | Проверьте, что файл скопирован в папку с материалами, а имя и расширение совпадают с путём в `media-index.js`. Попробуйте открыть этот путь напрямую через тот же сервер. |
| Страница есть, но кнопка «Начать» не работает | Проверьте наличие `media-index.js` и `database.js`. В `index.html` индекс должен подключаться перед базой, а база — перед скриптом игры. |
